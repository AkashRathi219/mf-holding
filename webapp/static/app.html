API reference

All endpoints require Authorization: Bearer <token>.

  "http://localhost:8000/api/schemes?category=Equity&limit=5"
curl -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"scheme_ids": [1436, 2510]}' \
  http://localhost:8000/api/overlap
